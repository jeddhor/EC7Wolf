# EC7Wolf 1.0-beta322

EC7Wolf's beta number counts commits since milestone `20ee748`; it is separate
from its engine base, ECWolf 1.4.2-9-g1bff92d (18 February 2026), on upstream's
1.5.0pre line. This remains a prerelease beta.

## Newer SDL_mixer and SDL_net (#59)

The Windows release and the Android APK now ship SDL_mixer 2.8.2 and SDL_net
2.4.0, up from 2.8.1 and 2.2.0. SDL itself was already at its newest SDL2
release, 2.32.10. Linux builds use your distribution's own SDL libraries, so
nothing changes there.

- **SDL_mixer 2.8.2** is a bug-fix release. Its Ogg Vorbis decoder, which
  plays the CD soundtrack, is faster, and its built-in decoders are updated.
- **SDL_net 2.4.0** adds two TCP functions. The game's multiplayer uses UDP,
  which is unchanged. The new Windows `SDL2_net.dll` no longer depends on
  `msvcrt.dll`.

## Building from source

Two fixes for people building EC7Wolf themselves:

- The installer's last-resort route, which builds SDL from source on a machine
  with no SDL packages, could never finish. SDL_mixer stopped asking for codec
  libraries such a machine will not have, and the installer then looked for the
  wrong name of the file that build installs. It now leaves out the codecs
  Corridor 7 does not use and accepts either name.
- `tools/fetch_android_deps.sh` kept whatever version was already downloaded,
  so after a version change it went on building the old one. It now replaces
  an unmodified copy, and stops on one with local changes.

## Compatibility and validation

No gameplay or rendering changes: the network protocol stays at 18, so beta317
to beta322 can play together, and saves are unaffected.

Against the new libraries, the CD soundtrack, sound, bot netplay and all 18
multiplayer gates pass, as do the Android build and installer gates.

Release installers, engine/editor packages and the Android APK are rebuilt by
the repository's release workflow. They contain no commercial Corridor 7 game
files; provide your own copy of the game.
