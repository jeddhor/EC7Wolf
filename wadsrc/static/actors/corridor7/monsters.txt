// Bandor disguise tuning, shared by the four furniture slots below.
//
// A Bandor is supposed to be scenery until the player is on top of it -- the
// guide tells the player to check behind them after walking into a furnished
// room. Left as an ordinary monster it unfolds the moment it sees or hears
// anything, so a shot fired two rooms away turns every chair on the floor into
// an alien before the player has even opened the door, and the ambush never
// happens once.
//
// The original's trigger condition is not documented and no radius survives in
// any source, so this is a deliberate design choice rather than a
// reconstruction: sight and hearing are both capped at four tiles. Beyond that
// it is furniture and stays furniture.
//
// Distances are in the engine's sight units, which are fixed-point times 64 --
// one tile is 65536*64 = 4194304, so four tiles is 16777216. (Compare MINSIGHT
// in wl_state.cpp, which is 1.5 tiles written the same way.)
//
// What this produces in play: facing the player it unfolds at four tiles;
// facing away the field-of-view test holds it until the player is inside the
// automatic close-range radius of 1.5 tiles, so they walk past it and it comes
// up behind them. Both read as an ambush, which is the point.
//
// Deliberately NOT limited: a Bandor killed nearby still calls the others in.
// That path is P_AlertCorridor7MonstersNear, which wakes them directly instead
// of going through the sight check, so the documented loyalty behaviour is
// unaffected by the hearing cap.
